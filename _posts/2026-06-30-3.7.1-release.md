Pachli 3.7.1 is now available. This release fixes a handful of issues discovered during the work to implement support for Mastodon's new [Collections](https://blog.joinmastodon.org/2026/06/mastodon-4.6#collections) feature. That work is not ready for widespread use yet, but should be available in the Pachli release scheduled for the end of July 2026.

## Significant bug fixes

### Show polls attached to boosted posts

[Julie Moynat](https://eldritch.cafe/@juliemoynat) reported (#[2316](https://github.com/pachli/pachli-android/issues/2316)) that boosts of posts containing polls were not showing the poll.

Fixed with #[2317](https://github.com/pachli/pachli-android/pull/2317).

### Show roles on any suggested accounts

The list of [Suggested accounts](/pachli/2024/06/27/2.6.0-release.html#show-suggested-accounts) wasn't showing any [roles](/2025/07/30/2.15.0-release.html#combat-phishing-by-highlighting-roles-on-accounts) those accounts had.

Fixed with #[2352](https://github.com/pachli/pachli-android/pull/2352).

### Update "following" relationships when following suggested accounts

For some of Pachli's anti-harassment controls (e.g., [hiding conversations started by accounts you do not follow](/pachli/2025/02/28/2.10.0-release.html#anti-harassment-controls-for-conversations-private-mentions)) Pachli maintains an on-device private database of the accounts you follow, and refreshes this periodically.

Following an account from the [Suggested accounts](/pachli/2024/06/27/2.6.0-release.html#show-suggested-accounts) screen wasn't updating this database, so there was a window of time where you could be following an account, but it would be treated as un-followed by any of the anti-harassment features.

Fixed with #[2350](https://github.com/pachli/pachli-android/pull/2350).
